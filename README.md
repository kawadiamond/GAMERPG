# ①課題名
GAME RPGアプリ

## ②課題内容（どんな作品か）
- スタートボタンを押すと敵（任意の文字列）が現れる。ATTACKボタンを押して倒しましょう！
- 敵を倒したら勲章として保存できます。

## ③アプリのデプロイURL
(https://kawadiamond.github.io/GAMERPG/kadai/index.html)

## ⑤工夫した点・こだわった点
- 勲章として倒した敵を保存できます。文字数が多いほど貴重な敵です。
- 敵のＨＰ０になったらＡＴＴＡＣＫボタンを非表示にする。
- 勲章をのこすかユーザーに聞く

## ⑥難しかった点・次回トライしたいこと（又は機能）
- localstorageに保存する内容をどうするか悩んだ。
- 経験値を作りたい。
- 文字列が同じものが並んだらイベント発生するなどしてみたい。
